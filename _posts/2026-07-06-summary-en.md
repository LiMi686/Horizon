## [Anthropic Discovers Global Workspace in Language Models](https://www.anthropic.com/research/global-workspace) ⭐️ 8.0/10

Anthropic's research identifies a shared subspace of representations, termed the 'global workspace' or J-Space, in language models that integrates information across different contexts. This subspace is analogous to the Global Workspace Theory of human consciousness. This finding provides a new lens for understanding how large language models reason and integrate information, potentially advancing AI interpretability and safety. It also reignites discussions about the relationship between AI and consciousness. The J-Space is defined as the subspace where small changes in layer activations most affect the final output logits, based on information geometry. The research shows that this subspace is shared across diverse prompts and tasks, suggesting a common reasoning pathway.

hackernews · in-silico · Jul 6, 17:44 · [Discussion](https://news.ycombinator.com/item?id=48808002)

**Background**: Global Workspace Theory (GWT), introduced by Bernard Baars in 1988, proposes that consciousness arises from a global workspace that integrates information from specialized modules. Anthropic's research applies this concept to language models, identifying a similar integrative subspace. This work builds on prior interpretability research at Anthropic, such as circuit tracing and attribution graphs.

Facebook has open-sourced Astryx, a fully customizable design system built on React and StyleX, which has been used internally for 8 years across over 13,000 apps. Astryx is currently in beta and ships with a CLI, dark mode, and ready-to-ship templates; it avoids styling lock-in by allowing overrides via className with any CSS approach, and its components are designed to be composed at any level.

## [Anthropic Releases Claude Code Agentic Coding Tool](https://github.com/anthropics/claude-code) ⭐️ 8.0/10

Anthropic has released Claude Code, an agentic coding tool that operates in the terminal, understands codebases, and automates tasks via natural language commands. It can be installed via curl, Homebrew, or WinGet, and integrates with IDEs and GitHub. Claude Code represents a practical application of large language models for autonomous coding assistance, potentially boosting developer productivity by automating routine tasks and complex code understanding. It competes with other agentic coding tools like OpenAI Codex CLI and Cursor. Claude Code requires Node.js 18+ and is available via multiple installation methods, with npm installation now deprecated. It includes plugins for custom commands and agents, and collects usage data for feedback, with privacy safeguards in place.
