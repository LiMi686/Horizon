## [vLLM v0.30.0 发布：新增 Fast Start 权重缓存与大量新模型支持](https://github.com/vllm-project/vllm/releases/tag/v0.30.0) ⭐️ 8.0/10

vLLM 发布了 v0.30.0，这是一次大型更新，包含来自 315 位贡献者（其中 104 位是新贡献者）的 762 个提交，新增了对 DeepSeek-V4.1-Flash、DeepSeek-V4-Flash-Vision-Exp、GLM-5.3-Flash、K2-Horizon、Cohere Compass、Bailing V3 VL 和 Nanbeige4.2 等模型的支持。本次最核心的特性是 Fast Start：一个常驻的每 GPU 权重缓存守护进程，将量化后、按张量并行切分的权重保留在 GPU 显存中，使引擎可以通过 CUDA IPC 配合 `--load-format ipc_cache` 快速重启，而无需从磁盘重新加载。 vLLM 是目前使用最广泛的开源大模型推理与服务引擎之一，因此它的版本发布直接影响生产团队部署和扩展模型的方式。Fast Start 能大幅缩短引擎重启与初始化时间，这对大规模服务集群中的自动扩缩容、滚动升级和故障恢复尤为重要；同时新增的模型与硬件支持也让 vLLM 跟上了开源模型快速演进的节奏。 Fast Start 现在还覆盖 FP4 检查点和多节点张量并行，守护进程为每块 GPU 运行一个进程，并通过 Unix 域套接字提供 CUDA IPC 句柄。其他值得注意的新增内容包括：兼容投机解码的 Gumbel-max 水印、面向稀疏 MLA 解码的 HiSparse 主机内存 KV 分层、Model Runner V2 的改进（在 H200 上把图捕获时间从 12 秒降到 2 秒，引擎初始化从 28.9 秒降到 8.2 秒），以及定向在线量化和 SM100/103 上默认启用 NVFP4 W4A16 等量化工作。

github · khluu · Sep 22, 05:20

**背景**: vLLM 是一个用于服务大语言模型的开源引擎，以 PagedAttention 等技术著称，可让高吞吐推理在显存使用上更高效。它支持众多模型架构和硬件后端，其版本发布受到在生产环境中运行大模型推理的团队密切关注。Fast Start 基于“缓存已加载权重”的思路：不再在每次重启时从磁盘读取并重新切分检查点，而是由守护进程把处理好的权重常驻在 GPU 显存中，并通过 CUDA IPC 交给新的引擎进程。MXFP8 是开放计算项目（OCP）微缩放（Microscaling）规范中定义的块级缩放 8 位格式，FlashMLA 则是 DeepSeek 优化的多头潜在注意力（MLA）内核库。

## [LLM 智能体通过 HLS 加 RTL 精修设计芯片，提速 2.6 倍](https://arxiv.org/abs/2609.21157) ⭐️ 8.0/10

一篇新的 arXiv 论文（2609.21157）比较了四种 LLM 智能体芯片设计流程——直接 RTL 设计、基于智能体的 HLS 设计、编译器后 HLS 精修以及 HLS 后 RTL 精修，并提出 AHRR，将基于智能体的 HLS 设计与 HLS 后 RTL 精修相结合。在面向 FPGA 的 11 项任务基准测试中，AHRR 相比直接 RTL 设计实现了 2.6 倍的几何平均加速，相关代码与评估工件已在 GitHub 上发布。 现有大多数 LLM 芯片设计工作都直接在 RTL 层面进行，而这篇论文通过实证表明，更高层次的抽象（HLS）结合低层次精修可以显著提升效果，为智能体硬件设计提供了一条具体的新工作流。如果这些权衡在 FPGA 之外也成立，可能会改变 LLM 智能体在芯片设计流程中的应用方式，并减少手工编写 RTL 的工作量。 该研究使用 FPGA 作为实用且易于部署的端到端评估平台，但作者指出他们所研究的设计流程权衡在很大程度上与目标工艺无关。案例研究表明，HLS 将设计知识提炼为智能体可利用的抽象，而 RTL 精修则能恢复纯 HLS 所遗漏的低层次优化机会。

rss · arXiv - AI · Sep 22, 04:00

**背景**: 高层次综合（HLS）可将数字系统的抽象行为规范自动转换为寄存器传输级（RTL）描述，使设计者能在更高抽象层次上工作。RTL 设计描述寄存器之间的数据流和逻辑操作，是集成电路设计流程中传统的手工编写阶段。FPGA 是包含可编程逻辑块阵列的可重构集成电路，是端到端评估硬件设计的便捷平台。

## [H^2V-M 在连续扰动区域上验证 VLM 与 VLA 的鲁棒性](https://arxiv.org/abs/2609.22293) ⭐️ 8.0/10

该论文提出了 H^2V-M，一种在 H^2V 验证框架基础上构建的、感知间隔（margin-aware）的收敛规则，并用它对六个视觉语言模型（来自 Gemma、InternVL、LLaVA 和 Qwen 系列）和五个视觉语言动作模型（来自 GR00T、OpenVLA 和 pi 系列）在亮度偏移、相机旋转及其组合构成的整个连续区域上进行了首次鲁棒性验证。论文报告称，H^2V-M 在模型查询次数上比 H^2V 提升一个数量级，并且比随机采样更快地找到反例，同时提供可靠性保证，使验证在 320 亿参数规模下变得可行。 现有基准只对扰动进行采样，因此无法保证未测试区域中不存在失败，这对日益部署于真实机器人和安全敏感应用中的 VLM 与 VLA 而言是一个关键缺口。通过在 320 亿参数规模上实现形式化的区域级鲁棒性验证，这项工作为具身智能系统获得更强的安全保障提供了一条可行路径。 验证覆盖了光度与几何扰动，包括亮度偏移、相机旋转及其组合，并发现鲁棒性主要取决于扰动类型而非模型本身，且 VLM 对大幅相机旋转的鲁棒性强于 VLA。对 VLA 而言，即使小至 ±1 度的扰动在许多情况下也会改变所下达的动作，并且鲁棒性更多取决于模型家族而非模型规模。

rss · arXiv - Computer Vision · Sep 22, 04:00

**背景**: 视觉语言模型（VLM）同时处理图像与文本，而视觉语言动作模型（VLA）在此基础上进一步输出机器人动作，其输入包括相机图像、语言指令和机器人状态。对录制的相机图像施加微小扰动（例如亮度变化或轻微相机旋转）就可能显著改变模型决策，因此鲁棒性验证的目标是证明在整个连续扰动区域内都不存在失败，而不仅仅是测试有限样本。H^2V 是为此目的提出的既有验证框架，而 H^2V-M 增加了感知间隔的收敛规则，使其对超大规模模型也可行。

## [干细胞移植逆转小鼠中风损伤](https://www.sciencedaily.com/releases/2026/09/260921081116.htm) ⭐️ 8.0/10

研究人员发现，干细胞移植能够使小鼠中风受损的脑组织再生，产生新的神经元并恢复丧失的运动功能。该疗法还改善了血管生成、减轻了炎症并增强了血脑屏障。 中风是全球长期残疾的主要原因之一，而现有治疗主要集中于急性期取栓，而非修复受损脑组织。如果这些多机制益处能在人体中重现，干细胞疗法有望为目前缺乏再生治疗选择的中风幸存者提供恢复功能的途径。 该研究是在小鼠身上进行的，因此仍处于临床前阶段，尚未证明在人体中的安全性或有效性。恢复过程涉及多种同时发生的机制——神经发生、血管化、抗炎和血脑屏障修复——而非单一通路，这可能使转化复杂化，但也提示了广泛的治疗潜力。

rss · ScienceDaily Health · Sep 22, 01:49

**背景**: 中风发生时，大脑某部分的血流被切断，导致神经元死亡，幸存者常留下永久性运动或认知障碍。成年大脑的自然修复能力有限，新神经元的产生（神经发生）主要局限于脑室下区和海马齿状回等少数区域。干细胞疗法旨在替代丢失的细胞并支持大脑环境，但早期研究显示移植细胞往往存活率低、与宿主组织整合有限。血脑屏障是由内皮细胞构成、保护大脑的选择性边界，中风后常被破坏，从而加重损伤。

## [脑部扫描发现长新冠疲劳与脑雾或源于多巴胺神经元受损](https://www.sciencedaily.com/releases/2026/09/260920222412.htm) ⭐️ 8.0/10

研究人员通过脑部扫描发现了证据，表明长新冠可能损害大脑中释放多巴胺的神经元，这或许能解释持续疲劳、动力不足、动作迟缓和记忆困难等症状。这一发现提示，未来或可开发针对大脑多巴胺系统的新疗法。 长新冠影响着全球数百万人，但其生物学病因仍不明确，因此确定具体的神经机制可能直接有助于诊断和治疗。如果得到证实，这项研究可能推动针对疲劳和认知症状的多巴胺靶向疗法研究。 这些证据来自脑部扫描而非尸检组织，因此该研究仍属初步阶段，尚不能证明多巴胺神经元损伤就是症状的成因。这些发现与已知的多巴胺在动机、运动控制和奖赏处理中的作用相符。

rss · ScienceDaily Health · Sep 22, 03:48

**背景**: 长新冠是指新冠感染后持续数周甚至数月的新发或持续症状，且不同患者的症状组合差异很大。多巴胺是大脑中一类特殊神经元产生的神经递质，参与调节动机、运动以及大脑的奖赏系统。由于疲劳、淡漠和动作迟缓是典型的多巴胺信号紊乱表现，研究人员一直怀疑多巴胺系统可能与长新冠有关。
