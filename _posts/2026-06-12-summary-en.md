## [Arbor: Tree Search as Cognition Layer for Autonomous Agents](https://arxiv.org/abs/2606.12563) ⭐️ 8.0/10

Arbor introduces a multi-agent framework that uses structured tree search as a cognition layer for autonomous agents, validated on full-stack LLM inference optimization, achieving up to 193% throughput-latency Pareto improvement over vendor-optimized baselines. This work demonstrates that tree-search-based multi-agent coordination can autonomously optimize complex, stateful systems like LLM inference, outperforming both vendor baselines and single-agent approaches, potentially reducing the need for manual engineering effort in performance tuning. Arbor uses an Orchestrator agent and a Critic agent with checks-and-balances, decomposing agent capabilities into hard skills (domain expertise) and soft skills (coordination protocols). It achieves run-to-run variance within 2 percentage points across multiple hardware generations, showing hardware-agnostic reproducibility.

**Background**: LLM inference optimization involves coordinating across the application, framework, compiler, kernel, and hardware stack, which traditionally requires engineering teams. Multi-agent systems with tree search can treat failures as diagnostic signals to guide exploration, unlike prior systems that operate on isolated targets with stateless evaluation.
