## [研究发现人类心肌细胞在心脏病发作后可再生](https://www.sciencedaily.com/releases/2026/09/260909231754.htm) ⭐️ 9.0/10

## [Google DeepMind 发布 AlphaGenome 基因组预测 API](https://github.com/google-deepmind/alphagenome) ⭐️ 8.0/10

Google DeepMind 发布了 AlphaGenome API，这是一个公开接口，可编程访问其统一的 DNA 序列模型，并在 GitHub 上提供了客户端代码、示例和文档。该 API 还开放了 AlphaGenome Atlas，这是一个包含全人类基因组预计算变异效应评分和特征重要性的资源，并对非商业用途免费提供。 通过向外部开发者和研究人员开放 AlphaGenome，DeepMind 降低了在计算生物学中应用最先进调控变异效应预测的门槛，可能加速对遗传病机制的研究。免费的非商业访问和预计算的 Atlas 数据集，可能使缺乏大规模计算资源的学术实验室也能开展全基因组分析。 AlphaGenome 可分析长达 100 万个碱基对的 DNA 序列，并对大多数输出以单碱基分辨率提供多模态预测，包括基因表达、剪接、染色质特征和接触图。该 API 最适合需要数千次预测的中小规模分析，但可能不适合超过 100 万次预测的大规模工作，且查询速率会随需求变化。

rss · GitHub Trending - Python · Sep 11, 23:46

**背景**: AlphaGenome 是 Google DeepMind 开发的大规模深度学习系统，用于预测 DNA 序列如何调控基因表达及其他基因组功能，并在众多变异效应预测基准上取得最先进的结果（详见 Avsec 等人的论文）。人类基因组大部分是非编码 DNA，负责调控基因活性，理解这些区域的变异如何影响功能是遗传学的核心挑战。该 API 让研究人员无需本地运行模型即可查询，而配套的 Atlas 则提供全基因组变异的预计算预测。

## [NCP-ArchPreview 将潜在空间语言模型扩展至 89 亿参数](https://arxiv.org/abs/2609.10715) ⭐️ 8.0/10

NCP-ArchPreview 提出了一种潜在空间语言模型，将下一词元预测（NTP）与下一概念预测（NCP）联合训练，模型会预测跨越多个词元的离散概念。该模型被扩展至 89 亿参数，并在 Dolma-3 数据集的 5.73 万亿词元上训练，是迄今为止潜在空间语言模型规模最大的一次验证。 这项工作通过引入显式的概念级目标，回应了标准自回归模型的一个根本局限，表明潜在空间建模可以提升训练效率与下游表现。它可能影响未来大语言模型的预训练方式，尤其是在数学等推理密集型任务上。 NCP-ArchPreview 仅消耗 51.3% 的总训练词元就达到了 OLMo-3-7B 的最终预训练损失，完整预训练后在下游宏平均上超过 OLMo-3-7B 2.45 分，其中 GSM8K 提升 5.99 分。所学到的潜在空间还支持轻量级领域适应——只需更新 1700 万参数的 VQ 模块；将概念表示注入 DFlash2 草稿模型后，平均接受长度提升了 4.17%。

rss · arXiv - NLP · Sep 11, 04:00

**背景**: 标准大语言模型通过下一词元预测进行预训练，即学习猜测序列中的下一个词。潜在空间语言模型则学习一种内部压缩表示（潜在空间），从而可以对概念等更高层单元进行建模。下一概念预测在此基础上让模型预测跨越多个词元的离散概念；而乘积量化是一种向量量化技术，通过将高维向量拆分为子空间，以较低成本构建大规模概念词表。

## [加州大学洛杉矶分校将脐带血干细胞转化为即用型抗癌 T 细胞](https://www.sciencedaily.com/releases/2026/09/260909231723.htm) ⭐️ 8.0/10

加州大学洛杉矶分校的研究人员将脐带血干细胞工程化改造为即用型 T 细胞，这些 T 细胞通过两套独立的识别系统攻击实体瘤。在小鼠实验中，单次给药即可控制癌症并延长生存期，同时避免了供体来源 T 细胞疗法的一种危险并发症。 如果该方法能转化到人类身上，就有望实现即用型 T 细胞疗法，无需采集并改造每位患者自身的细胞，从而让实体瘤治疗更快、更便宜、更易规模化。它还解决了移植物抗宿主病这一重大安全障碍，该并发症一直限制着供体来源 T 细胞的使用。 这些 T 细胞来源于脐带血干细胞，使用两套独立的识别系统来识别并攻击实体瘤——相比血液肿瘤，实体瘤用 CAR-T 治疗要困难得多。目前结果仍处于临床前阶段，仅在小鼠中通过单次给药得到验证，因此在人体中的安全性和有效性尚未得到证实。

rss · ScienceDaily Health · Sep 11, 01:08

**背景**: CAR-T 细胞疗法通过改造患者自身的 T 细胞来识别并摧毁癌细胞，但标准流程缓慢、昂贵且需要个体化定制。供体来源的 T 细胞可以提前制备，但存在移植物抗宿主病的风险，即供体免疫细胞攻击患者身体。脐带血富含年轻、可塑性强的造血干细胞，能够发育成多种血细胞类型，因此是这类疗法颇具吸引力的起始材料。
