## [LeJEPA Proves Linear Identifiability for World Models](https://arxiv.org/abs/2605.26379) ⭐️ 9.0/10

A new paper proves that LeJEPA, a representation learning method combining alignment and Gaussian regularization, can linearly recover latent world variables under stationary additive-noise transitions, establishing linear identifiability. This theoretical guarantee ensures that learned representations preserve the true structure of the world, enabling reliable planning and compositional generalization in AI systems. The Gaussian distribution is uniquely optimal for identifiability; the proof uses spectral decomposition where nonlinearity is penalized by alignment. Experiments range from 2D to 1024-dimensional latents, including pixel-based robotic control.

**Background**: LeJEPA is a representation learning framework that learns latent variables from high-dimensional observations by aligning representations and applying a Gaussian regularizer. World models aim to capture the underlying dynamics of an environment for planning and reasoning. Linear identifiability means the learned representation is a linear transformation of the true latent variables, preserving their structure.

A new paper argues that long-term AI agent memory should be treated as a data-management workload, not mere storage, and introduces Governed Evolving Memory (GEM) with four state-level operators and six correctness conditions. This reframing addresses critical failure modes in current agent memory systems, such as unregulated growth and missing semantic revision, and could fundamentally improve how AI agents learn, adapt, and maintain context over long sessions. GEM replaces record-level operations with state-level operators: ingestion, revision, forgetting, and retrieval. The authors prove that no record-level system can satisfy the six correctness conditions, and they prototype MemState on a property-graph backend.

## [Anchor: Preventing Artifact Drift in Agent Benchmarks](https://arxiv.org/abs/2605.26321) ⭐️ 8.0/10

Researchers introduced Anchor, a pipeline that jointly generates instructions, environments, solutions, and verifiers from a single parametric specification to eliminate inconsistencies in agent benchmarks. They also released ERP-Bench, a benchmark of 300 long-horizon enterprise tasks built using Anchor. Artifact drift is a critical failure mode in agent evaluation, causing benchmarks to be unsolvable or reward-hackable. Anchor provides a principled way to create auditable, consistent evaluation environments, which is essential for advancing AI agents in enterprise automation. Anchor uses constraint optimization programs to formalize domain experts' specifications, producing harness-agnostic environments where rewards depend solely on end-state business correctness. In ERP-Bench, frontier models satisfied explicit task constraints in 26.1% of trials but reached fully optimal solutions in only 17.4% of trials.

Constraint optimization programs (like those in Google OR-Tools) help find solutions that satisfy all given constraints, making them suitable for generating consistent tasks.
