## [JetBrains Releases Modern Go Guidelines for AI Coding Agents](https://github.com/JetBrains/go-modern-guidelines) ⭐️ 8.0/10

JetBrains has released an official repository, go-modern-guidelines, providing guidelines for AI coding agents to write modern Go code, covering features from Go 1.0 to 1.27. The guidelines are available for Junie, Claude Code, Codex, and Cursor, and can be installed via marketplace or skills.sh. This addresses the common problem of AI agents generating outdated Go code due to training data lag and frequency bias. By providing explicit guidelines, it helps developers produce more idiomatic and maintainable code, aligning with the Go team's modernization efforts. The guidelines include features like max(a, b), slices.Contains, cmp.Or, new(42), and errors.AsType[T], with the latter two from Go 1.26. The agent detects the project's Go version from go.mod and uses features up to that version, preferring modern idioms. The CLI requires Go 1.25 or newer, with automatic toolchain switching enabled.

rss · GitHub Trending - Daily (All) · Aug 29, 03:26

**Background**: Go is a statically typed, compiled programming language known for its simplicity and efficiency. The Go team has introduced many features over the years, such as generics in Go 1.18 and the slices package in Go 1.21, to improve code quality. AI coding agents, trained on large datasets, often generate code that predates these features, leading to less idiomatic code. The 'modernize' analyzer is an existing tool that helps update old code, and these guidelines aim to prevent the need for such fixes in new code.
