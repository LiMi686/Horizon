## [xAI 开源 Grok-1，一个 314B 参数的 MoE 大语言模型](https://github.com/xai-org/grok-1) ⭐️ 9.0/10

xAI 发布了开源权重模型 Grok-1，这是一个 314B 参数的混合专家（MoE）大语言模型，并提供了用于加载和运行的 JAX 示例代码。权重可通过种子文件和 Hugging Face Hub 获取。 此次发布使前沿规模的模型权重公开可用，使研究人员和开发者能够研究和微调如此规模的模型。这标志着开源 AI 的重要一步，可能加速创新，同时也引发关于运行此类模型所需资源的讨论。 该模型使用 8 个专家的混合专家架构，每个 token 激活 2 个专家，共 64 层，48 个查询注意力头，8 个键/值头，嵌入大小为 6,144。它支持 8,192 个 token 的上下文长度，并包含旋转嵌入和 8 位量化等功能，但提供的 MoE 实现并未针对效率进行优化。

## [大语言模型自发形成类似人脑的模块化认知架构](https://arxiv.org/abs/2608.13567) ⭐️ 9.0/10

一篇新的预印本论文（arXiv:2608.13567）报告称，大语言模型会自发形成与人脑功能特化相平行的模块化认知架构。通过跨越语言、形式推理、社会推理和物理推理四个认知领域的 46 项任务的电路分析，作者发现，在人脑中调用相同网络的任务会在大语言模型中招募重叠的神经元，而调用不同网络的任务则招募不同的神经元。 这一发现表明，模块化可能是智能系统的基本属性，而不仅仅是生物大脑进化中的偶然现象。它对人工智能的可解释性、模型设计以及我们对人工和人类认知的理解具有重要意义，可能引导更类脑、更高效的架构。 该研究在四个认知领域的 46 项任务中采用了电路分析，比较了大语言模型中的神经元招募模式与已知的人脑网络组织。该论文为预印本，尚未经过同行评审，因此其结论应被视为初步结果。

rss · arXiv - AI · Aug 17, 04:00

**背景**: 人脑表现出功能特化，不同的网络分别支持语言、对他心的推理以及对物理世界的推理。大语言模型（LLM）是在海量文本数据上训练的人工神经网络，近期研究探索了它们是否也会形成类似的功能特化。这项工作建立在先前研究的基础上，这些研究表明基于 Transformer 的语言模型与人脑之间存在共享的功能特化，并使用了电路分析——一种追踪信息在模型内部组件中流动的技术——来研究模块性。

## [AI 生成的 GitHub Copilot Autofix 在 Snowflake 的 Jira 集成中引入严重漏洞](https://www.wiz.io/blog/red-agent-snowflake-copilot-cicd-bug) ⭐️ 8.0/10

Wiz Red Agent 独立发现并利用了由 GitHub Copilot Autofix 引入的 GitHub Actions 漏洞，在无需人工干预的情况下访问了 Snowflake 内部 Jira 中的敏感数据。这标志着 AI 生成的代码在 CI/CD 管道中造成严重安全漏洞的一个真实案例。 这一事件凸显了 AI 生成代码带来的日益增长的安全风险，尤其是在 CI/CD 工作流中，漏洞可能产生广泛影响。它强调了在 AI 贡献中采用静态分析工具和仔细的人工审查的紧迫性，以防止企业环境中发生类似的安全入侵。 该漏洞是通过一个 GitHub Actions 工作流文件（jira_issue.yml）引入的，该文件使用了模板注入，允许通过模板扩展进行代码注入。该问题由 zizmor（一个用于 GitHub Actions 的静态分析工具）识别，并在工作流的第 24 行标记了错误。

hackernews · galnagli · Aug 17, 14:18 · [社区讨论](https://news.ycombinator.com/item?id=49331423)

**背景**: GitHub Copilot Autofix 是一个 AI 驱动的功能，可自动建议代码漏洞的修复方案。然而，在这个案例中，AI 生成的代码引入了新的漏洞。GitHub Actions 是一个 CI/CD 平台，用于自动化软件工作流，而 YAML 文件定义了这些工作流。模板注入发生在用户输入未经适当清理就嵌入模板时，允许攻击者执行任意命令。
