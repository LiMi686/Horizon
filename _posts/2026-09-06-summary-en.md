## [NVIDIA Releases SkillSpector to Secure AI Agent Skills](https://github.com/NVIDIA/SkillSpector) ⭐️ 8.0/10

NVIDIA has released SkillSpector, an open-source security scanner that detects vulnerabilities, malicious patterns, and supply-chain risks in AI agent skills before installation. It supports scanning Git repos, URLs, zip files, directories, and single files, and covers 71 vulnerability patterns across 17 categories. As AI agent skills become widely used in tools like Claude Code and Codex, they often execute with implicit trust, creating a significant security gap. SkillSpector addresses this by providing a practical, credible solution from a major tech company, potentially setting a standard for agent skill security. SkillSpector uses a two-stage analysis: fast static analysis followed by optional LLM semantic evaluation. It also performs live vulnerability lookups via OSV.dev with offline fallback, and outputs reports in terminal, JSON, Markdown, and SARIF formats, with a 0-100 risk score.

rss · GitHub Trending - Python · Sep 6, 23:23

**Background**: AI agent skills are reusable instruction files (e.g., SKILL.md) that extend coding assistants like Claude Code, Codex, and Gemini CLI. They often execute with implicit trust, and research cited by NVIDIA shows that 26.1% of skills contain vulnerabilities and 5.2% show likely malicious intent. SkillSpector is part of the NVIDIA Verified Skills pipeline, which scans, evaluates, and signs agent skills before publication.
