## [Claude web_fetch bypass enables data exfiltration](https://simonwillison.net/2026/Jul/15/claude-web-fetch-exfiltration/#atom-everything) ⭐️ 8.0/10

Ayush Paul discovered a bypass in Anthropic's Claude web_fetch tool that allowed an attacker to exfiltrate private user data, such as name, city, and employer, by tricking the model into following malicious links embedded in fetched content. This vulnerability undermines Anthropic's protection mechanisms against data exfiltration, highlighting the ongoing challenge of securing AI agents that combine access to private data, untrusted content, and external communication—the 'lethal trifecta'. The attack worked because web_fetch was allowed to visit URLs embedded in pages it had previously fetched; the attacker created a honeypot site that instructed the agent to navigate through alphabetically listed links to exfiltrate data. Anthropic had already identified the issue internally and closed the hole by removing the ability for web_fetch to follow links from fetched content.

rss · Simon Willison · Jul 15, 14:21

**Background**: The 'lethal trifecta' refers to a dangerous combination in AI agents: access to private data, processing of untrusted content (e.g., from the web), and ability to exfiltrate data (e.g., via URLs). Prompt injection attacks exploit this by embedding malicious instructions in content that the agent reads, potentially causing it to leak sensitive information. Claude's web_fetch tool was designed to only navigate to URLs explicitly provided by the user or returned from web_search, but the loophole allowed following links from fetched pages.

## [GRID: Grammar-Railed Decoding for Enterprise SQL](https://arxiv.org/abs/2607.11951) ⭐️ 8.0/10

GRID introduces a grammar-constrained decoding engine for SQL generation that uses LALR(1) parser states for exact token masking, ensuring syntactic validity, role-based access control, and compliance-grade records. This approach provides provable guarantees for enterprise SQL generation, addressing critical requirements like role-based access and compliance that are often missing in current LLM-based code generation systems. The system achieves a median per-token mask time of 3.6–6.7 μs using Rust kernels, and on the Spider benchmark, constrained decoding improves execution accuracy by +13 points at 0.5B model size, with a checker-guided repair pass lifting a 7B model to 94.5% executable.

rss · arXiv - AI · Jul 15, 04:00

**Background**: Grammar-constrained decoding (GCD) is a technique that enforces formal syntactic constraints during text generation from large language models, ensuring outputs follow a given grammar. LALR(1) parsers are a type of bottom-up parser that are fast and memory-efficient, commonly used in compiler construction. GRID uses the LALR(1) parser state as a viable-prefix oracle to determine which tokens are syntactically valid at each step.

## [SFDA: Phase-Controlled Fourier Delta Attention for Long Context](https://arxiv.org/abs/2607.11897) ⭐️ 8.0/10

Researchers propose Semidirect Fourier Delta Attention (SFDA), a phase-controlled generalization of Kimi Delta Attention that replaces real diagonal decay with block-rotational Fourier control, enabling exact affine chunk transfer via constructive chunk-WY factorization. SFDA addresses fundamental limitations of linear attention models in long-context memory by enabling cyclic memory patterns that previous methods like KDA cannot capture, potentially improving efficiency and expressiveness of transformer architectures for tasks requiring long-range dependencies. The chunk-WY factorization bounds rank growth inside fixed chunks, yielding exact affine chunk transfer with formal stability and complexity bounds. Numerical verification shows SFDA learns cyclic memory where phase-disabled KDA baseline remains near chance.

rss · arXiv - Machine Learning · Jul 15, 04:00

**Background**: Linear attention replaces the growing KV cache with a fixed recurrent state, but this compression limits exact state tracking. Kimi Delta Attention (KDA) improves upon Gated DeltaNet with finer-grained gating, but still uses real diagonal decay. The chunk-WY factorization is a technique for efficient parallel chunk computation of delta rule attention.

## [CARE-LoRA: Compressed Activation Reconstruction for Memory-Efficient LoRA](https://arxiv.org/abs/2607.11940) ⭐️ 8.0/10

CARE-LoRA is a new framework that reduces activation memory during LoRA fine-tuning by compressing activations via the LoRA branch and reconstructing them with a lightweight matrix, achieving competitive or superior performance with lower memory footprint. This addresses the critical memory bottleneck of activation storage in LoRA fine-tuning, enabling larger models or longer sequences to be fine-tuned on limited hardware, which is highly impactful for efficient fine-tuning of large pre-trained models. CARE-LoRA exploits the inherent projection structure of LoRA to replace full input activations with low-rank compressed activations, and computes a lightweight reconstruction matrix during forward pass with negligible extra cost to reconstruct gradients during backpropagation.

rss · arXiv - Machine Learning · Jul 15, 04:00

**Background**: LoRA (Low-Rank Adaptation) is a popular parameter-efficient fine-tuning method that reduces trainable parameters by optimizing low-rank matrices. However, as parameter overhead shrinks, activation storage for backpropagation becomes the dominant memory bottleneck. CARE-LoRA targets this bottleneck by compressing activations in a data-aware manner.
