## [AirLLM Enables 70B Model Inference on a Single 4GB GPU](https://github.com/lyogavin/airllm) ⭐️ 8.0/10

AirLLM, an open-source tool, dramatically reduces GPU memory requirements for large language model inference, allowing 70B models to run on a single 4GB GPU without quantization, distillation, or pruning. It also supports running 405B Llama 3.1 on 8GB, DeepSeek-V3 (671B) on ~12GB, and Kimi K3 (2.8T) on under 4GB VRAM. This breakthrough enables edge inference of large models on consumer hardware, democratizing access to state-of-the-art AI. It could significantly reduce hardware costs and open new possibilities for on-device AI applications. AirLLM uses a layered inference approach, loading only the required layer from disk during execution and freeing memory afterward, reducing per-layer memory to about 1.7GB for 70B models. For sparse MoE models like Kimi K3, it streams one expert at a time, further reducing memory usage.

**Background**: Large language models (LLMs) typically require massive GPU memory, e.g., a 70B model at FP16 needs about 140GB, far exceeding consumer hardware. AirLLM's approach avoids quantization or pruning, which can degrade model quality, by instead optimizing memory management during inference.

The Rust project has formally adopted a project goal to introduce immobile types and guaranteed destructors, proposing new traits like Move and Forget. This could eventually deprecate the Pin type, which was previously used to handle immovable values. This addresses a long-standing gap in Rust's type system, enabling safer and more ergonomic handling of self-referential types and scoped concurrency. It could simplify async/await internals and unlock patterns like safe scoped threads, impacting the broader systems programming ecosystem. The proposal introduces traits such as Move and Forget to make capabilities explicit, allowing types to opt out of being moved or forgotten. It also mentions !Destruct (must-move types) for linear types, and notes that the design may change significantly before implementation.

**Background**: Rust currently assumes all types can be moved and forgotten, which complicates self-referential types and scoped concurrency. This project brings a specialized, high-performance inference path for DeepSeek V4 Flash to consumer hardware, potentially enabling local execution of a 284B-parameter MoE model on high-memory Macs and multi-GPU servers. It also demonstrates a trend toward narrow, model-specific inference engines that leverage aggressive quantization and compressed KV caches for practical local AI. DwarfStar treats the KV cache as a first-class disk citizen for long contexts and is optimized for 2-bit quantization on 96GB+ MacBooks. It includes a server API, tool calling, and an integrated coding agent, and supports multi-GPU CUDA systems, DGX Spark, and ROCm on Strix Halo systems like the Framework Desktop.

## [BART's Gaussian Process Limit and Random Tree Features](https://arxiv.org/abs/2607.28844) ⭐️ 8.0/10

This paper proves that as the number of trees in BART grows to infinity, the model converges to a Gaussian process with a specific kernel. It also introduces random tree features that achieve minimax-optimal learning rates for ridge regression, with rates depending only logarithmically on dimension. This work provides a novel theoretical foundation for BART's empirical success, linking it to Gaussian processes and offering a computationally efficient alternative to MCMC. It also broadens BART's applicability by enabling integration into any model with a linear predictor, which is significant for Bayesian nonparametrics and machine learning theory. The kernel and its reproducing kernel Hilbert space (RKHS) have favorable inferential properties that help explain BART's performance. The random tree features approximation allows practitioners to use BART within debiased machine learning estimators, which require fast convergence rates.

**Background**: Bayesian Additive Regression Trees (BART) is a sum-of-trees model for nonparametric regression, where each tree acts as a weak learner. Previous theoretical work focused on posterior contraction rates that depend strongly on the number of covariates, but this paper takes a different approach by studying the infinite-tree limit, revealing a connection to Gaussian processes. Random tree features are a computational shortcut that approximates this limiting process, enabling efficient ridge regression.
