## [MicroPython + WASM Sandbox for Python Code Execution](https://simonwillison.net/2026/Jun/6/micropython-in-a-sandbox/#atom-everything) ⭐️ 8.0/10

Simon Willison released an alpha package called micropython-wasm that compiles MicroPython to WebAssembly, enabling safe execution of Python code within a sandbox. He also built a Datasette Agent plugin, datasette-agent-micropython, to demonstrate its use. This approach provides a practical way to sandbox Python code with memory and CPU limits, file access restrictions, and network isolation, which is crucial for running untrusted plugins or user-provided code in applications like Datasette. It leverages WebAssembly's built-in security guarantees without requiring complex OS-level sandboxing. The micropython-wasm package is available on PyPI and can be installed via pip; it wraps a custom-compiled WebAssembly build of MicroPython. The sandbox restricts file system access to a temporary directory, limits memory and execution time, and disables network access by default.

rss · Simon Willison · Jun 6, 03:53

**Background**: Sandboxing Python code is notoriously difficult due to the language's dynamic nature and extensive standard library. WebAssembly (WASM) provides a portable binary instruction format that runs in a sandboxed environment with well-defined resource limits. MicroPython is a lean implementation of Python 3 designed for microcontrollers, but it can also be compiled to WASM for use in browsers or server-side runtimes.

## [OpenAI Launches Lockdown Mode to Block Prompt Injection Data Theft](https://simonwillison.net/2026/Jun/5/openai-help-lockdown-mode/#atom-everything) ⭐️ 8.0/10

OpenAI has officially launched Lockdown Mode, a security feature that limits outbound network requests from ChatGPT to prevent data exfiltration during prompt injection attacks. It is rolling out to eligible personal and business accounts, including Free, Plus, Pro, and self-serve ChatGPT Business tiers. Prompt injection attacks are a critical AI safety risk, and Lockdown Mode directly addresses the data exfiltration leg of the 'Lethal Trifecta'—a combination of private data access, untrusted content, and a data theft channel. By cutting off the exfiltration vector deterministically, this feature significantly enhances security for high-risk users without relying on AI-based defenses that could be subverted. Lockdown Mode does not prevent prompt injections from appearing in processed content, such as cached web pages or uploaded files, but it blocks outbound requests that could transfer sensitive data to an attacker. OpenAI CISO Dane Stuckey noted that the mode is not meant for everyone and comes with tradeoffs in functionality and utility, making it best suited for users with elevated risk profiles.

rss · Simon Willison · Jun 5, 23:56

**Background**: Prompt injection is a cybersecurity exploit where malicious inputs cause unintended behavior in large language models (LLMs). Data exfiltration refers to the unauthorized transfer of data from a system to an external destination. The 'Lethal Trifecta' describes a scenario where an LLM system has access to private data, is exposed to untrusted content, and has a way to steal and transmit data—Lockdown Mode breaks this chain by restricting the exfiltration channel.

Headroom is an open-source context compression layer that reduces token usage by 60–95% before sending data to LLMs, supporting six compression algorithms and three integration modes: library, proxy, and MCP server. This significantly cuts token costs and latency for AI agents and LLM applications, making large-scale deployment more economical and efficient. It addresses a critical bottleneck in AI workflows where context windows are expensive and limited. Headroom offers a local-first, reversible compression approach with a dedicated model (Kompress-base) on Hugging Face. It integrates as a Python/TypeScript library, a standalone proxy, or an MCP server, and is available on PyPI and npm.

rss · GitHub Trending - Daily (All) · Jun 6, 22:58

**Background**: LLMs process tokens, which are units of text, and charge per token. Long contexts (e.g., tool outputs, logs, RAG chunks) can quickly consume tokens, increasing costs and slowing responses. Context compression reduces the size of inputs without losing essential information, similar to how image compression reduces file size.

## [GITCO Boosts Time Series Forecasts by Suppressing Harmful Patches](https://arxiv.org/abs/2606.05332) ⭐️ 8.0/10

Researchers propose GITCO, a lightweight inference-time framework that selectively identifies and suppresses harmful input patches in time series foundation models, achieving a +1.95% MASE reduction on TimesFM 2.5 across 53 datasets. This addresses context poisoning, a critical issue where anomalous patches degrade zero-shot forecast quality in patch-based TSFMs, without requiring parameter updates, making it practical for real-world deployment. GITCO consists of three components: Gate, Router, and Critic, and captures 89.9% of the improvement upper bound. The paper also introduces context sensitivity profiles as a new property of TSFMs.

rss · arXiv - AI · Jun 6, 04:00

**Background**: Time series foundation models (TSFMs) like TimesFM are pre-trained on diverse time series data and can forecast unseen datasets in zero-shot manner. However, patch-based TSFMs are vulnerable to context poisoning, where anomalous input patches disproportionately affect attention and degrade accuracy. GITCO optimizes the input context at inference time to mitigate this.

## [Synthetic Contrastive Reasoning Boosts Multi-Table QA](https://arxiv.org/abs/2606.05382) ⭐️ 8.0/10

Researchers constructed a synthetic contrastive reasoning-trace dataset for multi-table QA and fine-tuned LLMs using Contrastive Preference Optimization (CPO), achieving 9.7%-16.3% absolute improvements over supervised fine-tuning on Qwen3-14B, Mistral-8B, and Llama-3.1-8B. This work addresses the lack of reasoning supervision in multi-table QA, enabling LLMs to perform more accurate compositional reasoning across relational tables, which is critical for real-world applications like database querying and data analysis. The dataset includes validated positive traces and plausible negative traces generated by heterogeneous LLMs, and CPO fine-tuning yields gains up to 21 percentage points on the MMQA benchmark. Ablations confirm that heterogeneous generators strengthen the contrastive signal.

rss · arXiv - AI · Jun 6, 04:00

**Background**: Multi-table QA requires models to retrieve evidence, link schemas, and perform compositional reasoning across multiple relational tables. Existing datasets often provide only questions and final answers without intermediate reasoning steps, limiting model training. Contrastive Preference Optimization (CPO) is a learning method that trains models to prefer correct outputs over plausible but incorrect ones by contrasting preferred and dispreferred responses.

## [LLM Judges Can Be Manipulated After Initial Decision](https://arxiv.org/abs/2606.05384) ⭐️ 8.0/10

A new paper demonstrates that LLM judges, while stable under neutral reevaluation, can be manipulated to reverse their initial decisions through targeted post-decision conversation. The study introduces the Evaluation Robustness Score (ERS) to quantify interactional robustness. This vulnerability undermines the reliability of LLM-as-judge evaluation pipelines widely used in benchmarking, potentially leading to inaccurate rankings and harmful evaluation changes. The findings highlight the need for evaluation protocols that measure robustness under challenge, not just static agreement. Experiments on MT-Bench and AlpacaEval show that authority framing is especially destabilizing, and revised judgments often come with low-overlap justifications, suggesting post hoc rationalization. The anti-baseline challenge protocol and counterbalanced target-validation protocol were used to isolate manipulability effects.

rss · arXiv - AI · Jun 6, 04:00

**Background**: LLM-as-judge evaluation is a common method where large language models are used to assess and rank outputs from other models. These evaluations typically assume that judgments are stable properties of fixed inputs, but this paper shows that post-decision interaction can alter outcomes.
