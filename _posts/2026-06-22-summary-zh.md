## [Headroom：AI 代理的上下文压缩层](https://github.com/chopratejas/headroom) ⭐️ 8.0/10

Headroom 是一个开源上下文压缩层，可将 AI 代理的 token 使用量减少 60-95%，同时保持答案质量，可作为库、代理或 MCP 服务器使用。 该工具通过大幅减少 token 消耗，直接解决了 LLM 应用中的关键成本和延迟瓶颈，使 AI 代理对开发者来说更高效、更经济。 Headroom 支持六种压缩算法，本地优先且可逆，可通过 Python/TypeScript 库、代理服务器或作为 MCP 服务器集成到代理框架中。

rss · GitHub Trending - Daily (All) · Jun 22, 23:14

**背景**: 大型语言模型（LLM）将输入处理为 token，更长的上下文会增加成本和延迟。上下文压缩在将 token 发送到 LLM 之前减少其数量，从而提高效率而不牺牲答案质量。MCP（模型上下文协议）是连接 AI 代理与工具和数据的标准，可实现无缝集成。

## [THUDM/slime：开源的大语言模型强化学习后训练框架](https://github.com/THUDM/slime) ⭐️ 8.0/10

THUDM 发布了 slime，这是一个用于强化学习扩展的开源大语言模型后训练框架，它将 Megatron 的高性能训练与 SGLang 的高效推理和数据生成连接起来。 slime 提供了一个经过实战检验的轻量级框架，已用于训练 GLM-5.2 等前沿模型，使先进的强化学习后训练更易于开源社区使用，并支持可重复的研究。 slime 支持多个模型系列，包括 Qwen、DeepSeek 和 Llama 3，并直接传递 Megatron 和 SGLang 参数，无需额外的抽象层，确保与上游优化的兼容性。
