## [ReactionAtlas：机器学习从种子分子构建化学反应网络](https://arxiv.org/abs/2606.30778) ⭐️ 9.0/10

ReactionAtlas 利用机器学习生成模型和 DFT 训练的机器学习力场，从少量种子分子自动构建化学反应网络，在益生元碳水化合物化学中发现了约 47,000 个反应和约 12,000 种化合物。 该方法绕过了传统缓慢的 DFT 过渡态搜索方法，实现了前所未有的反应网络映射规模和精度，可能改变催化、燃烧和生命起源研究等领域。 机器学习力场的过渡态在 85% 的情况下与 PBE0 参考值的 RMSD 在 0.5 Å 以内，该框架还发现了甲糖循环（一个关键的益生元反应网络）的替代反应路径。

rss · arXiv - Machine Learning · Jul 1, 04:00

**背景**: 化学反应网络映射连接基元反应的最小值和过渡态，但传统构建需要利用 DFT 寻找数万个过渡态，速度慢且需要反应物-产物对作为输入。ReactionAtlas 使用生成模型提出反应，并用机器学习力场筛选有效过渡态，从种子分子自动完成过程，无需手工规则。

## [FFmpeg 9.1 推出改进版 AAC 编码器](https://hydrogenaudio.org/index.php/topic,129691.0.html) ⭐️ 8.0/10

## [Cloudflare 推出基于 x402 的微支付网关](https://blog.cloudflare.com/monetization-gateway/) ⭐️ 8.0/10

Cloudflare 宣布推出 Monetization Gateway，该服务允许客户使用 x402 支付协议对任何资源（网页、API、数据集、MCP 工具）收费，该协议支持通过 HTTP 进行即时稳定币微支付。 这可能从根本上改变网络经济，为机器人流量和 API 访问实现无摩擦的微支付，有可能减少对 API 密钥和订阅模式的需求，同时为内容创作者创造新的收入来源。 Monetization Gateway 使用 x402 协议，这是由 Coinbase 开发的互联网原生支付开放标准，通过返回 HTTP 402 状态码来请求付款。早期访问侧重于网页、数据集、API 和 MCP 工具，并通过 x402 进行稳定币结算作为启动支付路径。

hackernews · soheilpro · Jul 1, 13:59 · [社区讨论](https://news.ycombinator.com/item?id=48746914)

**背景**: HTTP 402 状态码最初保留用于未来的支付系统，但从未被广泛采用。x402 是一个新标准，利用稳定币（如 USDC）实现直接通过 HTTP 的即时、低成本微支付，绕过了传统的支付轨道。Cloudflare 的网关充当反向代理，拦截请求并在转发到源服务器之前强制执行支付策略。

研究人员推出了 TheraJudge，一个通过基于偏好的优化训练的开源治疗评估器，以及 TheraAgent，一个多智能体系统，利用 TheraJudge 的评估通过专门的批评者、教练和治疗师角色迭代优化治疗回应。 该框架表明，基于人类对齐的评估采取行动，而非仅仅依赖更强的生成能力，能显著提升基于 LLM 的心理健康支持的治疗质量，实现了人类评分质量提升 0.43 分和 96%的临床医生评分者间信度。 TheraJudge 在 7 个心理维度上评估回应，与临床医生评分的组内相关系数（ICC）达到 0.87-0.95，超越了监督基线和强大的闭源评估器。TheraAgent 的迭代优化过程对低质量回应（5 分制中≤3 分）实现了 94%的恢复率，提升了 2.45 分。

rss · arXiv - NLP · Jul 1, 04:00

**背景**: 大型语言模型（LLM）越来越多地被用于心理健康支持，但确保治疗质量仍然具有挑战性。传统的评估指标往往无法提供可操作的改进反馈。基于偏好的优化，如直接偏好优化（DPO），利用人类偏好数据训练模型，使输出与人类价值观对齐。多智能体系统涉及多个专门的 AI 智能体协作解决复杂任务。

## [RADIANT-PET：大语言模型与强化学习减少 PET/CT 假阳性](https://arxiv.org/abs/2606.28392) ⭐️ 8.0/10

研究人员提出了 RADIANT-PET 框架，该框架将宽松的分割模型与大语言模型裁决和强化学习（GRPO）相结合，以减少 PET/CT 病灶分割中的假阳性。 这项工作通过增加一个模拟临床解读的推理层，解决了肿瘤影像学中的一个关键挑战，有望改善自动肿瘤检测并减少不必要的后续检查。 该框架使用组相对策略优化（GRPO）微调本地大语言模型进行病灶级推理，并可选择结合放射学报告作为额外上下文，在提供报告时取得了最大的改进。

rss · arXiv - Computer Vision · Jul 1, 04:00

**背景**: PET/CT 成像对癌症诊断至关重要，但由于生理性摄取和伪影，容易出现假阳性。传统的深度学习分割模型常常过度分割，包括正常高摄取器官。RADIANT-PET 引入了一种两阶段方法：首先以高灵敏度生成候选区域，然后使用大语言模型将每个候选区域分类为真实病灶或假阳性。

## [SGD 在稳定性边缘实现自稳定](https://arxiv.org/abs/2606.30930) ⭐️ 8.0/10

本文为随机梯度下降（SGD）在稳定性边缘提供了精确的收敛保证，表明随机性会导致交替的动力学阶段，但 SGD 能自稳定动力学，从而在使用大学习率时实现收敛。 这项工作填补了优化理论中的一个关键空白，分析了现代深度学习广泛使用但此前仅针对确定性梯度下降研究的稳定性边缘 SGD 动力学。它解释了 SGD 为何能在大学习率下有效工作，这对高效训练大型模型至关重要。 该分析针对线性分类器和两层神经网络的多类交叉熵损失，证明了 SGD 能在固定迭代次数内恢复稳定性。实验验证了理论结果，并突出了 SGD 在大步长设置下的优势。

rss · arXiv - Data Science & Statistics · Jul 1, 04:00

**背景**: 稳定性边缘（EoS）是一种现象，其中梯度下降使用非常大的学习率，导致损失振荡但总体仍下降。此前，EoS 仅针对确定性梯度下降被理解，随机情况（SGD）尚未探索。本文将理论扩展到 SGD，表明随机噪声实际上有助于稳定训练。
