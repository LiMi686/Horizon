## [Relational Structural Causal Models](https://arxiv.org/abs/2606.14892) ⭐️ 9.0/10

A new paper introduces relational structural causal models (RSCMs), extending Pearl's structural causal models to handle varying objects and relations, and proposes relational neural causal models (RNCMs) that are provably correct. This work bridges causal reasoning and combinatorial generalization, enabling AI to reason about interventions and counterfactuals in environments with varying numbers of objects, which is crucial for applications like autonomous driving and robotics. The paper shows that without additional assumptions, causal and observational queries about unseen object combinations cannot be identified; it defines relational causal graphs and symbolic identification criteria to enable identification even with unobserved confounding.

**Background**: Structural causal models (SCMs) are a framework for causal reasoning using directed acyclic graphs, but they assume a fixed set of variables. Relational learning deals with data where objects and their relationships vary. This work combines both to handle causal queries in relational domains.

## [Stop Using JWTs for Browser Sessions](https://gist.github.com/samsch/0d1f3d3b4745d778f78b230cf6061452) ⭐️ 8.0/10

A widely shared gist argues that JSON Web Tokens (JWTs) should not be used for browser-based user sessions due to security and revocation concerns, sparking intense debate in the developer community. This debate affects how millions of web applications handle authentication, potentially shifting best practices away from JWTs for session management and toward traditional session cookies or alternatives like PASETO. The gist links to external articles that criticize JWT for lacking built-in revocation, and community comments note that revocation lists or short-lived tokens with refresh can mitigate these issues. The discussion also highlights that JWTs remain suitable for service-to-service communication.

hackernews · dzonga · Jun 16, 16:49 · [Discussion](https://news.ycombinator.com/item?id=48558147)

**Background**: JWTs are self-contained tokens that encode claims and are signed, allowing stateless verification without server-side storage. However, this statelessness makes it difficult to revoke a token before its expiration, a key requirement for user sessions. Session cookies, by contrast, rely on server-side storage and can be revoked instantly. The debate centers on whether the convenience of JWTs outweighs their security drawbacks for browser-based authentication.
