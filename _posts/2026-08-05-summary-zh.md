Uber 已开源 ADR（Agentic AI Detection and Response），这是一套已在生产环境中部署的企业级 AI 代理安全系统，包含 ADR Sensor、ADR-Bench 和 ADR Detector 组件。相关论文已被 MLSys 2026 接收。 此次发布回应了企业环境中保护 AI 代理安全的迫切新兴需求，提供了一个经过生产验证的框架，结合了可观测性、基准测试和威胁检测。它可能为 AI 代理安全树立标准，并加速各行业安全采用 AI 代理。 ADR-Bench 包含 300 多个任务、133 个 MCP 服务器，并覆盖全部 17 种代理攻击技术。ADR Prevention 组件未包含在当前开源版本中，离线 ADR Explorer 引擎也未包含在内。

## [Cloudflare Computer：在 Durable Object 中为代理提供虚拟文件系统](https://github.com/cloudflare/computer) ⭐️ 8.0/10

Cloudflare 发布了 Cloudflare Computer，这是一个预览包，在 Durable Object 内提供虚拟文件系统，权威状态存储在 SQLite 中，并通过可插拔的执行表面暴露。它提供了三个后端：带 FUSE 挂载的容器、运行 just-bash 的隔离 shell，以及隔离的 JavaScript 后端。 这引入了一种新颖的方法，为 AI 代理提供持久、统一的文件系统，并支持多种执行环境，可能简化代理基础设施，并支持更复杂的代理工作流。它可能影响开发者在 Cloudflare 边缘平台上构建有状态代理应用的方式。 Durable Object 在 SQLite 中保存权威状态，并通过 workspace.runtime.exec(source, { backend }) 暴露单一执行入口。容器后端使用沙箱端守护进程 (computerd) 将状态挂载为 FUSE 文件系统，并通过 capnweb RPC 同步更改；而隔离 shell 和 JavaScript 后端在 Dynamic Worker 中运行，并通过 Workers RPC 通信。该包明确标记为仅预览，API 不稳定，不适合生产使用。

rss · GitHub Trending - Daily (All) · Aug 5, 22:51

**背景**: Cloudflare Durable Objects 是一种特殊的 Cloudflare Worker，结合了计算和存储，支持有状态的无服务器应用。FUSE（用户空间文件系统）允许用户空间程序实现文件系统，而 capnweb 是 Cloudflare 开发的 JavaScript 原生 RPC 协议。该项目利用这些技术为代理创建虚拟文件系统。
