## [RFC 10008 Defines New HTTP QUERY Method](https://www.rfc-editor.org/info/rfc10008/) ⭐️ 8.0/10

RFC 10008, published on April 1, 2025, introduces the HTTP QUERY method, a new HTTP request method that is both safe and idempotent, allowing a request body to be sent with semantics similar to GET but with a payload. This fills a gap in HTTP where developers previously had to misuse GET (which technically shouldn't have a body) or POST (which is not idempotent) for queries with complex parameters. It improves cacheability and reliability for search-like operations. The QUERY method is defined as safe and idempotent, meaning it does not change server state and can be safely retried. The request body describes how the target resource should process the query, and caching mechanisms must consider the body as part of the cache key.

hackernews · schappim · Jun 17, 10:51 · [Discussion](https://news.ycombinator.com/item?id=48568502)

**Background**: HTTP defines several request methods, with GET being the standard for retrieving resources without side effects, and POST for submitting data that may change state. However, GET does not support a request body, and POST is not idempotent, making it unsuitable for queries that need to be safely retried or cached. The new QUERY method addresses this by providing a safe, idempotent method with a body.

## [DivInit: Boosting Agentic Search with Diverse Queries](https://arxiv.org/abs/2606.17209) ⭐️ 8.0/10

This addresses a key limitation in scaling agentic search breadth—query redundancy—with a simple, training-free intervention that consistently improves performance, making agentic systems more effective for complex reasoning tasks. DivInit draws n candidates from a single LLM call, selects k diverse seeds, and runs them as parallel trajectories, avoiding overlapping evidence from redundant first queries. The method is training-free and code is available on GitHub.

**Background**: Agentic search uses LLM agents to break down complex queries into sub-tasks and retrieve information iteratively. Multi-hop QA requires combining information from multiple sources through multi-step reasoning. Standard parallel sampling in agentic search often yields diminishing returns because initial queries across rollouts are redundant, leading to overlapping evidence.

## [Structural Uncertainty: New Metric for LLM Reasoning Consistency](https://arxiv.org/abs/2606.17312) ⭐️ 8.0/10

Researchers propose structural uncertainty, a framework that measures LLM reasoning consistency by analyzing the stability of self-preference rankings among multiple candidate solutions, using Bradley-Terry modeling and PageRank.
