## [Kyutai Labs 发布轻量级 CPU 文本转语音模型 Pocket TTS](https://github.com/kyutai-labs/pocket-tts) ⭐️ 8.0/10

Kyutai Labs 发布了 Pocket TTS，这是一个拥有 1 亿参数的轻量级文本转语音模型，可在 CPU 上高效运行，在 MacBook Air M4 上仅使用 2 个 CPU 核心即可达到约 6 倍实时速度。它支持语音克隆、音频流以及多种语言，包括英语、法语、德语、葡萄牙语、意大利语和西班牙语。 Pocket TTS 通过消除对 GPU 的需求，使高质量语音合成在普通设备上即可实现，从而普及了文本转语音技术。其小巧的尺寸和 CPU 高效性支持设备端部署，与基于云的 API 相比，降低了延迟和隐私问题。 该模型采用连续音频语言模型架构，包含两个协作组件：FlowLMModel 用于生成潜在音频序列，解码器用于波形合成。它需要 PyTorch 2.5+，支持 Python 3.10 至 3.14，首个音频块的延迟约为 200 毫秒。

rss · GitHub Trending - Daily (All) · Jul 10, 22:54

**背景**: 文本转语音（TTS）系统传统上需要强大的 GPU 才能进行实时推理，这限制了其使用范围，仅能用于云服务器或高端硬件。Kyutai Labs 是一家位于巴黎的开放科学 AI 研究实验室，获得了 3 亿欧元资助，致力于通过开放研究普及 AI。Pocket TTS 设计为可在 CPU 上运行，包括通过 WebAssembly 在浏览器中运行，使其能够被更广泛的用户使用。

## [LMCache：面向 LLM 推理的 KV 缓存管理层](https://github.com/LMCache/LMCache) ⭐️ 8.0/10

LMCache 是一个开源的 KV 缓存管理层，通过优化键值缓存的存储和检索来加速 LLM 推理，近期更新包括新的多进程架构和多节点 P2P CPU 内存共享。 LMCache 解决了 LLM 推理中的关键瓶颈，降低了内存占用和延迟，使得大语言模型能够在不同硬件和服务框架上更高效、可扩展地部署。 LMCache 是厂商中立的，可与 vLLM 等主流服务引擎集成，支持分层内存层级（GPU、CPU、磁盘），已被 NVIDIA Dynamo 和 CoreWeave 采用。它还支持多模态模型以及包括 AMD、Arm 和 Ascend 在内的跨硬件平台。

rss · GitHub Trending - Python · Jul 10, 22:54

**背景**: 在 LLM 推理中，KV 缓存存储中间键和值的计算结果以便在文本生成时重用，避免重复计算。然而，其内存占用随上下文长度线性增长，带来了可扩展性挑战。LMCache 在多个内存层级间管理该缓存，以提高效率并降低延迟。

本文提出了首个在高维 Procrustes 匹配中实现恒定相关性下精确恢复的多项式时间算法，该算法利用宽树的加权计数。 这一突破填补了低维与高维场景之间的空白，使得高维点集的对齐在统计学和机器学习中具有实际应用价值。 当 d ≥ polylog(n) 且 ρ² > √α（α ≈ 0.338 为 Otter 树计数常数）时，算法以高概率成功。信息论下界表明，当 ρ² ≳ max{log n/d, √(log n/n)} 时恢复是可能的。

**背景**: Procrustes 匹配涉及通过未知排列和旋转对齐两个点集。先前工作集中于低维（d = O(log n)），而高维（d ≫ log n）需要近乎完美的相关性。本工作借鉴图匹配问题中的树计数技术。

## [分数精度不能保证扩散采样的数值稳定性](https://arxiv.org/abs/2607.08757) ⭐️ 8.0/10

一篇新论文表明，分数匹配中的前向边际误差小并不能保证反向时间扩散采样的数值稳定性，欧拉-丸山离散化尽管弱收敛，但在 Wasserstein 距离上发散。 这挑战了扩散模型中的一个基本假设，意味着仅靠分数匹配精度不足以实现可靠的采样，可能影响基于扩散的生成模型在实际中的可信度。 作者构造了一个光滑的分数场，其前向边际 L2 误差任意小，但欧拉-丸山离散化在概率上收敛，而每个正矩发散，导致所有 Wasserstein 距离 W_p（p≥1）发散。他们还表明，将学习到的去噪器投影到包含数据支撑的有界凸集上可以恢复 Wasserstein 收敛。

rss · arXiv - Data Science & Statistics · Jul 10, 04:00

**背景**: 扩散模型通过逆转逐渐添加噪声的前向扩散过程来生成数据。分数匹配训练神经网络来近似含噪数据分布的分数（对数密度的梯度）。反向时间采样通常使用欧拉-丸山等方法进行离散化，数值稳定性对于生成高质量样本至关重要。Wasserstein 距离衡量概率分布之间的差异，Wasserstein 距离发散表明样本质量差。
