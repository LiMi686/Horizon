## [GRPO, Dr. GRPO, DAPO Unified as One Operation on Standard Deviation](https://arxiv.org/abs/2607.00152) ⭐️ 9.0/10

A new paper proves that three popular reinforcement learning methods for training language models to reason—GRPO, Dr. GRPO, and DAPO—are equivalent operations on the standard deviation of answer correctness, unified under a single group-standard-deviation identity. This unification reveals a fundamental insight: the training update size is exactly the disagreement among sampled answers, meaning split groups teach the most while unanimous groups teach nothing. It simplifies the design space for LLM reasoning training and clarifies where learning happens. GRPO divides by the standard deviation, Dr. GRPO drops the division, and DAPO discards groups where the standard deviation is zero. The paper validates the identity on the Big-Math difficulty dataset and in a controlled training run.

rss · arXiv - Data Science & Statistics · Jul 2, 04:00

**Background**: GRPO (Group Relative Policy Optimization) is a reinforcement learning algorithm that fine-tunes LLMs by comparing responses within a group, avoiding a separate value network. Dr. GRPO (GRPO Done Right) fixes a length-related bias by normalizing with a constant. DAPO (Decoupled Clip and Dynamic Sampling Policy Optimization) introduces decoupled clipping and dynamic sampling to improve stability and efficiency.

## [Linux 6.9 LUKS Suspend Fails to Wipe Encryption Keys](https://mathstodon.xyz/@iblech/116769502749142438) ⭐️ 8.0/10

A regression in Linux kernel 6.9 (May 2024) caused the cryptsetup luksSuspend command to stop wiping disk-encryption keys from memory during suspend, leaving master keys exposed in RAM. This security regression undermines the protection of encrypted disks during suspend, as an attacker with physical access could extract the master key from memory, potentially decrypting the entire disk. The bug was introduced in Linux 6.9 and affects systems using the Debian-originated cryptsetup-suspend addon, which relies on luksSuspend to wipe keys on suspend and prompt for passphrase on resume.

hackernews · IngoBlechschmid · Jul 2, 15:25 · [Discussion](https://news.ycombinator.com/item?id=48763035)

**Background**: LUKS (Linux Unified Key Setup) is the standard for disk encryption on Linux. The luksSuspend command temporarily suspends an encrypted device, wiping the master key from memory so that on resume the user must re-enter the passphrase. Without this wipe, the key remains in RAM during sleep, making it vulnerable to cold boot attacks or other memory access techniques.

This paper combines these ideas with contextual bandits, which allow for personalized decisions based on context, to study oversight under two-sided informational asymmetry.
